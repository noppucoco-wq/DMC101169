# แดชบอร์ดข้อมูลนักเรียน สพป.ลำปาง เขต 2

แดชบอร์ดสรุปจำนวนนักเรียนและห้องเรียนรายโรงเรียน ภาคเรียนที่ 2 ปีการศึกษา 2569
ข้อมูลที่โรงเรียนยืนยันและรับรองแล้ว ณ วันที่ 10 พฤศจิกายน 2569

- **ภาพรวม** – ตัวเลขสรุปทั้งเขต กราฟนักเรียนรายชั้น สรุปตามระดับ โรงเรียนตามขนาด และการจัดอันดับ
- **ค้นหาโรงเรียน** – ค้นด้วยชื่อหรือรหัส กรองตามขนาดและระดับที่เปิดสอน คลิกเพื่อดูรายละเอียดรายชั้น

**ผู้รับผิดชอบ:** นายนพชัย สิทธิ ศึกษานิเทศก์ชำนาญการพิเศษ
ปฏิบัติหน้าที่ผู้อำนวยการกลุ่มส่งเสริมการศึกษาทางไกล เทคโนโลยีสารสนเทศและการสื่อสาร สพป.ลำปาง เขต 2

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าแดชบอร์ด |
| `style.css` | รูปแบบและสี |
| `app.js` | การคำนวณ กราฟ และการค้นหา |
| `data/students.js` | ข้อมูลรายโรงเรียนที่หน้าเว็บใช้ |
| `data/students.csv` | ข้อมูลชุดเดียวกันสำหรับดาวน์โหลด |
| `vendor/d3.min.js` | ไลบรารีวาดกราฟ D3 v7 |

เป็นเว็บไซต์แบบไฟล์คงที่ ไม่ต้องติดตั้งหรือ build ใด ๆ เปิด `index.html` ในเบราว์เซอร์ได้ทันที

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (ต้องเป็น Public หากใช้บัญชีฟรี)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ระดับบนสุดของ repository
3. ไปที่ **Settings → Pages** เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด **Save**
4. รอประมาณ 1–2 นาที เว็บไซต์จะอยู่ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repository>/`

## ปรับปรุงข้อมูลรอบถัดไป

แทนที่ `data/students.js` และ `data/students.csv` ด้วยข้อมูลชุดใหม่ที่มีหัวคอลัมน์เดิม
แล้วแก้วันที่และภาคเรียนใน `index.html` (ส่วนหัวและท้ายหน้า) ตัวเลขและกราฟจะคำนวณใหม่เอง
